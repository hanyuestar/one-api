# 模型倍率说明

## 倍率是什么

one-api 用「倍率」来统一度量不同模型的消耗。基准是：

> **1 倍率 = $0.002 / 1000 tokens（美元）**
> **1 倍率 = ¥0.014 / 1000 tokens（人民币）**

也就是说，美元定价的模型，`倍率 = 官方 input 价格($/1M) ÷ 2`；人民币定价的模型，`倍率 = 官方 input 价格(元/1M) ÷ 14`。

## 倍率在哪里设置

后台 → 设置 → 倍率设置 → **模型倍率**。这是一个 JSON 格式的配置，key 是模型名，value 是倍率数值。

首次部署时系统会用代码中的默认倍率初始化。之后每次启动，如果默认列表里有新模型而数据库没有，会自动补充（不会覆盖已手动修改的值）。

## 关于 CompletionRatio

部分模型的 input 和 output 价格比例不一致。`CompletionRatio` 记录的是 output 价格 ÷ input 价格的比例，用于精确计算抵扣额度。如果某个模型的 output 价比 input 贵得多，它的 CompletionRatio 就会更大。

## 手动调整

后台修改倍率后立即生效，无需重启。如果想让某个模型的用户多花钱或少花钱，直接改倍率数值即可。比如把某个免费模型的倍率从 0 改到 0.5，用户调用时就会消耗额度。

把整个倍率 JSON 删掉再保存，系统会用默认值重新初始化，适合大规模回滚。
